# Security policy

This project is under development. Security fixes target the latest development
version until a supported release series is announced.

Report vulnerabilities privately using the repository's GitHub security advisory
feature when enabled. If private advisories are unavailable, open an issue requesting
a private reporting channel without disclosing the vulnerability. Include affected versions, a minimal
synthetic reproducer, and the potential impact. Do not include licensed standards
or sensitive EPICS data in a public issue.

Maintainers will acknowledge reports, reproduce the issue, and coordinate a fix and
disclosure with the reporter. No response or remediation deadline is promised.
