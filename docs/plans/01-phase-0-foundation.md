build docs, and cut a release from, before any format code exists. Estimated effort: 2 to 3

## 0.4 Package skeleton

Create empty modules matching the layout in `00-overview.md` with module docstrings that
state the owning clause: `diagnostics.py`, `encoding.py`, `lexer.py`, `values/`, `model/`,
`codecs/`, `knowledge/`, `validation/`, plus `py.typed`.

Implement `diagnostics.py` fully in this phase because every later phase uses it:

```
class Severity(StrEnum): ERROR, WARNING, INFO, SKIPPED
class Diagnostic(BaseModel):
    code: str            # e.g. "E4.2.1", "C5-16"
    severity: Severity
    message: str
    clause: str | None   # "4.2", "5(n)"
    line: int | None; column: int | None
    section: str | None; object_id: str | None; property: str | None
class DiagnosticSink: collects, filters by severity, has_errors(), raise_if_errors()
class EpicsError(Exception): carries list[Diagnostic]
```

Tests: construction, ordering by (line, column), `raise_if_errors` behaviour, JSON dump of a
diagnostic (the CLI will print these).

## Acceptance criteria

- Fresh clone, `uv sync --all-extras --group dev`, `uv run pytest` passes with the
  diagnostics tests, `uv run pre-commit run --all-files` is clean, `uv run mkdocs build
  --strict` succeeds, `uv build` produces `ace_epics-0.0.1-py3-none-any.whl`.
- CI green on both OS targets. A dry-run tag `v0.0.1rc0` publishes to TestPyPI.
- `git check-ignore "ASHRAE 135.1-2025.pdf"` prints the path.
