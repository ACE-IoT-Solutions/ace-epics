# ADR 0001: Apache License 2.0

Date: 2026-10-11
Status: accepted

## Context

ace-epics is a protocol library intended for reuse by vendors and test-tool authors.
The implementation plan selects a permissive license with an explicit patent grant.
Licensed standards documents are private source material and are not project code.

## Decision

License project code under the Apache License 2.0 and distribute its text in LICENSE.
Knowledge tables contain identifiers and interpreted facts with source-edition
attribution; licensed PDFs and verbatim extracts remain ignored and uncommitted.

## Consequences

Contributions use Apache-2.0 unless separately agreed. Fixtures must be synthetic.
The project license grants no rights to redistribute ASHRAE standards documents.
